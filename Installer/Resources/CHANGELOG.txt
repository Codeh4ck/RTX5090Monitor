1.0.2 - Generic NVIDIA GPU monitoring and desktop improvements
- Add GenericNvidia for desktop GeForce RTX cards, with a GPU selector and shared hardware polling.
- Show GPU status alongside ASUS and WireView pin charts, with an optional standalone tab.
- Add core voltage, optional widget hotspot temperature and reported fan duty.
- Keep the existing widget fan layout and show widget temperatures with one decimal place.
- Add GPU Status settings in iCUE and remove Connected badges from widget pages.
- Preserve existing ASUS temperature thresholds and warning policies during migration.
- Match desktop GPU status and power cards to the existing icon-based design; use a full-width status panel.
- Add the GPU usage label and separate temperatures and fans in the standalone desktop tab.
- Rename Nvidia configuration and save the optional GPU Status tab preference; require the tab when neither WireView nor Astral is reporting.
- Place the optional GPU Status tab before MSI PSU.
- Add a saved startup-tab selection, free window resizing and maximization, and remembered window dimensions.
- Fix the GPU Status tab crash caused by rebuilding rows during loading and accessing an unloaded icon.

1.0.1 - Fresh-install configuration fix
- Fix fresh installations failing with Invalid service configuration and the 30-second /health timeout.
- Preserve default warning settings when bootstrap configuration contains empty objects.
- Add regression coverage for fresh startup using the shipped configuration.

1.0.0 - Component versions and update checks
- Desktop, backend service and iCUE widget start at version 1.0.0.
- version.json is the shared build and published release manifest.
- Desktop and widget can check at startup and daily, weekly or monthly.
- Manual checks, 24-hour reminders and skip-version actions link to the matching GitHub release.
- Desktop checks its own version and the running backend version through GET /version.
- Offline checks do not interrupt live monitoring; updates and widget import remain manual.
- Installer includes the required .NET, Windows App SDK and Visual C++ runtimes.
- Run setup to upgrade an installer-managed installation while retaining settings.

0.4.0 - Shared warning policies and coordinated component update
- New service, desktop and iCUE widget version 0.4.0; update all three together.
- Plugin-owned warning definitions and detection, with a service-built catalogue.
- Configurable initial notifications, five-second default reminders, recovery confirmation and per-warning overrides.
- Stable warning episodes prevent reading changes from causing notification spam.
- ASUS temperature thresholds are configured in the ASUS plugin settings; existing warning policies migrate automatically.
- Desktop panels, WireView read-only settings window, fault presentation and debug simulation improvements.
- Widget chart radius, enforced decimal places, comparison badges and shared warning flyouts.
- Installer-managed service and app upgrade in place while retaining settings; import the new widget manually in iCUE.

0.3.1 - Windows version detection fix
- Read the actual Windows build from the 64-bit registry instead of MSI's compatibility build value.
- Accept supported Windows 10 and Windows 11 builds while retaining the minimum build and architecture checks.
- Add packaged OS detection tests, including evaluation on the build machine without executing an installation.

- Required local monitoring service with optional WinUI desktop app/configurator.
- Offline x64 setup, automatic delayed service start and recovery.
- Modify, repair, upgrade rollback and uninstall support.
