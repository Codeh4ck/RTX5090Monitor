Chart controls

In the app, select each metric and source with its checkbox, then use Start recording. Selection changes during recording apply from that moment. Stop recording keeps the session for review. Clear recording discards the stopped session and keeps your metric selections for the next recording.

Start / End move to the beginning or end of the recording. Back / Forward move by half the visible time range.

Drag the horizontal time scrollbar to browse the recording. With the scrollbar focused, use the arrow keys, Home, or End.

Zoom in / Zoom out change the visible time range. You can also scroll over a plot to zoom or drag across it to select a range. Shift-drag or Shift-scroll pans through time.

Include values in legend adds values beside each trace name. Values follow the hover timestamp while the popup is visible and show the latest loaded readings otherwise.

Fit session shows the complete recording. Follow latest toggles automatic movement to the newest readings. Browsing earlier times turns it off.

Hover over a plot to see the timestamp and nearest recorded values for all selected traces. Gaps display a dash. You can move into the popup to scroll a long list.

In the app, Export recording saves a recording data file or interactive HTML. Import recording reopens either format. In the HTML viewer, use Open recording to load saved recordings.
